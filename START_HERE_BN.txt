BOOKING SYSTEM
Customer prothome gaming setup select korbe, tarpor extras (max 6 controller + food/drinks), duration, station, date o time select korbe.
Booking submit hole unique `RSC-...` reference pabe. `/track` page-e code diye Pending/Confirmed/Rejected status dekhte parbe.
Payment gateway nei: customer bKash/Nagad select kore amount o optional TrxID likhbe. Admin nijer wallet check kore payment Verified korbe; booking confirmation o payment verification alada.
Admin panel > Gaming prices > Add setup diye notun console/station add korte parba. Station capacity o prottek duration-er price set koro.
Schedule-e confirmed slot `Booked` ebong pending request `Pending` dekhabe. Same station/time double-book block hobe.
